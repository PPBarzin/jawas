# Security Policy

Jawas is experimental research software and is not suitable for production financial use.

## Reporting

If you discover a security issue involving committed secrets, private key handling, or unsafe default behavior, report it privately to the repository maintainer before opening a public issue.

## Scope

Important classes of issues:

- accidental secret exposure
- unsafe transaction signing defaults
- misleading documentation that could encourage unsafe deployment

## Non-Goals

- guaranteeing execution profitability
- providing production-grade operational security
